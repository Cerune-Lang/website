このページは、Ceruneの構文と意味論を探すための **案内ページ** です。厳密な仕様は本体側で一元管理します。

## 主なトピック

| トピック | 説明 |
| --- | --- |
| 型と値 | 整数、浮動小数点、真偽値、文字列、配列 |
| 関数 | 引数、戻り値、呼び出し |
| データ型 | 構造体相当の積型、列挙型 |
| 制御フロー | 条件分岐、ループ、パターンマッチ |
| モジュール | ファイル間の参照と公開範囲 |
| 実行時の停止 | 演算上の失敗と診断 |

実装中・未対応の機能もあります。サポート状況は必ず一次資料で確認してください。
