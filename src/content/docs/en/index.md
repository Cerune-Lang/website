Cerune is an experimental programming language focused on making compiler transformations observable.

## Explore the docs

- **[Getting Started](/en/guide/getting-started/)** — Installation and your first program.
- **[Language Reference](/en/reference/overview/)** — An entry point for types, operations, and syntax.
- **[Compiler Internals](/en/internals/overview/)** — Explore the IR, transformations, and backends.
- **[Examples](/en/examples/overview/)** — Browse programs maintained in the language repository.

## Source of truth

This website is **secondary explanatory material**, not the normative specification. Consult [the Cerune repository](https://github.com/Cerune-Lang/Cerune/tree/master/docs) for precise semantics, implementation limits, and design decisions.

Use [Tint](https://tint.hokutaka.dev/) to experiment with Cerune code.
