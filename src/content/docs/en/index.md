Cerune is an experimental programming language supporting static typing, direct IR execution, VM execution, and code generation in multiple formats.

## Documentation

- **[Getting Started](/en/guide/getting-started/)** — Installation, source validation, and execution.
- **[Language Reference](/en/reference/overview/)** — Types, syntax, supported features, and limitations.
- **[CLI](/en/cli/overview/)** — Validation, execution, generation, and observation commands.
- **[Compiler Internals](/en/internals/overview/)** — IR, MIR, SSA, execution paths, and code generation.
- **[Examples](/en/examples/overview/)** — Programs maintained in the core repository and how to run them.

## Source documents

This website is **secondary explanatory documentation**. For precise definitions and implementation limits, consult the [Cerune language reference](https://github.com/Cerune-Lang/Cerune/blob/master/docs/reference/language.en.md) and [CLI reference](https://github.com/Cerune-Lang/Cerune/blob/master/docs/reference/cli.en.md).

[Tint](https://tint.hokutaka.dev/) provides an interface for inspecting Cerune source and compiler outputs.
