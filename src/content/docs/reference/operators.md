Ceruneでは、**演算する値の型と式の評価順**が決まっています。数値型を暗黙に変換せず、整数の桁あふれや不正なシフトを実行時に検査します。

## 算術演算

| 演算子 | 処理 | 対応する型 |
| --- | --- | --- |
| `+`・`-`・`*` | 加算・減算・乗算 | 整数、`f32`、`f64` |
| `/` | 除算 | 整数、`f32`、`f64` |
| `%` | 整数の剰余 | 整数のみ |
| 単項`-` | 符号反転 | 符号付き整数、浮動小数点 |

二項算術演算の左右は**同じ数値型**でなければなりません。型を決めていない整数リテラルには周囲の型が伝わりますが、すでに型がある異なる数値同士を自動で変換しません。

剰余`%`は、例えばリングバッファの書き込み位置を先頭へ戻すときに使えます。

```cerune
mut next: i64 = 3;
next = (next + 1) % 4;
print(next); // 0 — 末尾の次は先頭
```

整数の除算は**0方向へ丸め**ます。`-7 / 3`は`-2`、`-7 % 3`は`-1`です。剰余が0でない場合、その符号は左辺と同じです。

### 実行時に停止する整数演算

- `+`・`-`・`*`と符号付き単項`-`で、結果が元の型に収まらない場合。
- 整数の`/`・`%`で右辺が0の場合。
- 符号付き整数の最小値を`-1`で割る場合（`/`は停止、`%`は0になり成功）。

```cerune
amount: u8 = 250;
// print(amount + 10); // u8の最大値255を超えるため停止
```

**整数演算は暗黙に折り返しません。** 符号付き整数の最小値の符号反転も、型の最大値を超えるため停止します。停止前の出力は保持され、失敗した演算より後の処理は実行されません。

浮動小数点は`f32`と`f64`の精度でそれぞれ演算し、**最近接・偶数丸め**を使います。結果が変わる乗算と加算を、勝手にFMAへまとめません。詳しくは[浮動小数点の設計](https://github.com/Cerune-Lang/Cerune/blob/master/docs/design/float-rounding.ja.md)を参照してください。

## 比較演算

| 演算子 | 対応する型 | 戻り値 |
| --- | --- | --- |
| `==`・`!=` | 同じ型の数値、`bool`、文字列、配列、名前付き積型、直和型 | `bool` |
| `<`・`<=`・`>`・`>=` | 同じ数値型どうし | `bool` |

文字列や複合値の比較では、内容や要素・フィールドを順に調べます。直和型では選択中の選択肢とその値を比較し、最初の不一致で終了します。文字列の大小比較、`bool`の大小比較は未対応です。

```cerune
expected: [i64; 3] = [4, 7, 9];
actual: [i64; 3] = [4, 7, 9];
print(actual == expected); // true
```

## 論理演算と短絡評価

`!`、`&&`、`||`は**`bool`専用**です。整数の0と1は、真偽値の代わりに使えません。

| 式 | 右辺を評価する場合 |
| --- | --- |
| `left && right` | `left`が`true`のときだけ |
| `left \|\| right` | `left`が`false`のときだけ |
| `!value` | 単項演算。値を反転する |

```cerune
values: [i64; 2] = [4, 9];
index: i64 = 2;
print(index == 2 || values[index] == 9); // true
```

この例では左辺だけで`true`と決まるため、**範囲外の`values[2]`を読みません**。必要な右辺は一度だけ評価します。実行を省略した式に関数呼び出しや停止する演算があっても実行されません。

ただし、**左右とも名前解決と型検査は行います**。`false && unknown_name`や`true || 1`は、右辺を実行しなくてもコンパイルエラーです。

## ビット演算とシフト

ビット演算は8種類の整数型（`i8`〜`i64`、`u8`〜`u64`）に対応します。**`bool`や浮動小数点には使えません。**

| 演算子 | 処理 |
| --- | --- |
| `&` | 両方が1のビットを残す |
| `\|` | どちらかが1のビットを立てる |
| `^` | 片方だけ1のビットを立てる |
| `~` | 型のビット幅で反転する |
| `<<`・`>>` | 左・右へ指定ビット数だけ移動する |

例えば、読み取りと書き込みの権限をビットで管理できます。

```cerune
read: u8 = 1;
write: u8 = 2;

mut permissions: u8 = read | write;
print((permissions & write) != 0); // true

permissions = permissions & ~write;
print((permissions & write) != 0); // false
```

二項演算の左右とシフト量は**同じ整数型**です。シフト量は0以上、型のビット数未満に限ります。`u8`なら0〜7です。

- `0u8 << 8`は、元の値が0でもシフト量が無効なので停止します。
- `128u8 << 1`は、数学上の結果が`u8`に収まらないため停止します。
- 符号付き整数の右シフトは符号を保持します。`-3i8 >> 1`は`-2i8`です。
- `&`と`|`は**短絡評価しません**。論理演算の`&&`・`||`とは異なります。

## 評価順と優先順位

通常の二項演算は、**左辺を一度評価し、次に右辺を一度評価**します。左辺で停止したら右辺を評価しません。例外的に`&&`・`||`は不要な右辺を省略します。

演算子の優先順位は**強い順**に次のとおりです。

1. 単項`-`・`!`・`~`
2. `*`・`/`・`%`
3. `+`・`-`
4. `<<`・`>>`
5. `<`・`<=`・`>`・`>=`
6. `==`・`!=`
7. `&`、次に`^`、次に`|`
8. `&&`、最後に`||`

同じ順位の二項演算は左から結び付きます。**比較演算はビット演算より優先**されるため、フラグを検査するときは必ず`(flags & mask) != 0`のように括弧で意図を示してください。

## 現在の制限と一次資料

数値型どうしの暗黙変換、整数の暗黙の折り返し、ビットを捨てる左シフト、文字列の大小比較は未対応です。数値の型変換・丸め・飽和は別の**明示的な操作**で扱います（[型](/reference/types/)を参照）。

公式サンプルでは、演算子がどの処理に役立つか確認できます。

- [bit_flags.ceru](https://github.com/Cerune-Lang/Cerune/blob/master/examples/bit_flags.ceru) — 権限フラグの追加・判定・解除
- [ring_buffer.ceru](https://github.com/Cerune-Lang/Cerune/blob/master/examples/ring_buffer.ceru) — 剰余で配列の位置を循環させる
- [short_circuit.ceru](https://github.com/Cerune-Lang/Cerune/blob/master/examples/short_circuit.ceru) — 配列参照を守る短絡評価
- [aggregate_comparison.ceru](https://github.com/Cerune-Lang/Cerune/blob/master/examples/aggregate_comparison.ceru) — 複合値の等値比較
- [integer_limits.ceru](https://github.com/Cerune-Lang/Cerune/blob/master/examples/integer_limits.ceru) — 整数型の最大・最小値と桁あふれ
- [言語リファレンス（一次資料）](https://github.com/Cerune-Lang/Cerune/blob/master/docs/reference/language.ja.md)

このページは仕様の要約です。各整数型の値の範囲、型検査、評価順、停止条件は一次資料で確認してください。
